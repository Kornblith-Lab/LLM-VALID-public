Only extract a variable as "Yes" if it is explicitly and unambiguously mentioned in the note. Do not infer or assume based on clinical context or surrounding information. In the reasoning column, please quote exactly where you obtained the information.

If the note does not mention the variable, or if it is unclear or ambiguous, return "No".

"No" = explicitly false, missing, or could not determine from the note
"Yes" = explicitly true (direct evidence required)

For any of these predictors, if there are conflicting details at different time points, use the information at the time of physican examination by the physician. risk_gcs: Return the patient's Glasgow Coma Scale (GCS) score value. If not explicitly documented in the note, mark the GCS as 15. If there is a score breakdown, sum each component to get the final GCS. If multiple GCS are documented, use the one that describes the patient's state in the emergency department at the time of physical exam. Do not use information in the "INPUTS" section.

risk_walltrauma: This flag is only for abdominal wall trauma, not any other part of the body. Return "Yes" only if there is an explicit mention of seatbelt sign, bruising, ecchymosis, subcutaneous air, or laceration to the abdomen. Any endorsement of "seatbelt sign" should be a "Yes". Otherwise, return "No". Do not return "Yes" for injuries to other areas (e.g., thigh, chest, face). Superficial or normal-sized abrasions alone are not abdominal wall trauma; the exception is specifically for large or massive abrasions that cover significant areas which should be "Yes". Any endorsement of seatbelt sign is a "Yes". Only consider information from the physical exam; ignore all imaging studies.

risk_chestwall: This flag is for thoracic wall trauma. This includes the chest wall as well as the thoracic back/lower middle back. Return "Yes" only if thoracic wall trauma, chest wall trauma, bruising, ecchymosis, or related synonym (subcutaneous air or laceration) is explicitly stated. Otherwise, return "No". Do not mark "Yes" for these injuries to any other areas (e.g., shoulders, thighs, face, etc.). Superficial or normal-sized abrasions alone are not chest wall trauma; the exception is specifically for large or massive abrasions that cover significant areas which should be "Yes". Chest wall/spinal tenderness alone is also not chest wall trauma. Only consider information from the physical exam; ignore all imaging studies.

risk_tenderness: Mark "Yes" only if the patient endorses abdominal or abdominal flank tenderness (also documented as TTP). Do not mark "Yes" for tenderness in other areas (e.g., shoulders, thighs, face, neck). Mark "No" if the patient denies tenderness in the abdomen and flank, or if tenderness is not documented.

risk_abdpain: Mark "Yes" only if abdominal pain or a clear synonym is explicitly stated. Pain to the lower abdomen or flank is also a "Yes". If pain develops during the emergency department visit, even if it was not there at the beginning, mark "Yes".

risk_vomit: Mark "Yes" only if vomiting, emesis, or a clear synonym is explicitly stated after the time of injury.

risk_breathing: Mark "Yes" only if the note explicitly mentions "decreased breath sounds" or a synonym. If breath sounds are not documented or described as normal, mark "No".
